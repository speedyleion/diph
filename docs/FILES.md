# Files

| Key | Acts on the side or the window |
| --- | --- |
| `Ctrl+s` | saves the side the cursor is on |
| `F5` | reloads the files |
| `ZZ` | closes the window |

On macOS these are `Cmd+s` and `Cmd+r`. Saving writes the side the cursor is on
to its file, and reloading re-reads both files. Both are also on the **File**
menu, with the same shortcuts.
